# ghub-gui Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a GUI Qt6/QML (`ghub-gui`) que controla o `ghubd` por D-Bus: Visão geral, Sensibilidade, Configurações, instância única, abertura pela bandeja e empacotamento de usuário.

**Architecture:** Crate `crates/ghub-gui` = biblioteca sem Qt (`model`: lógica pura; `client`: trait `DaemonApi`, controlador de thread única com debounce/coalescência, `FakeDaemon`, cliente real zbus bloqueante, instância única) + binário com Qt (`backend.rs` cxx-qt fino, `qml/`). Atualizações vêm do controlador para o QObject por `qt_thread().queue`. Smoke headless do Qt confere por código de saída.

**Tech Stack:** Rust 2021, `cxx-qt`/`cxx-qt-lib`/`cxx-qt-build` **=0.10.0**, Qt 6.11 (Quick, Quick Controls `Basic`), zbus 5 bloqueante (sem tokio), `serde_json`.

**Spec:** `docs/superpowers/specs/2026-10-12-ghub-gui-design.md` (e a geral `2026-10-12-ghub-linux-design.md`). Mocks: https://claude.ai/artifact/SJAZxtEFWq5tiRotHBAN34. Em conflito, a spec manda.

## Review Focus

Classes de entrada/falha que a spec implica e nenhum caminho feliz exercita (cada uma tem teste na task dona):

1. Mouse conectado com `dpi_current == 0`, ou dormindo (`connected=false`): nunca mostrar "0 DPI"; controles desabilitados; último dispositivo esmaecido (T3, T7).
2. Rajada do slider: no máximo uma escrita por rajada com o **último** valor; ordem preservada frente a outros comandos; releitura chegando durante o debounce não reverte a edição (T4).
3. Daemon parado/reiniciado/lento no meio da sessão: estado `stopped` sem travar nem panicar, comando enquanto parado vira erro (não espera), recuperação sozinha em `NameOwnerChanged` (T4, T5).
4. DPI digitado inválido (vazio, 0, negativo, não múltiplo do passo, acima do máximo, `i64` enorme, faixa 0/0 de mouse offline) nunca é enviado (T2).
5. Nomes de perfil (vazio/espaços, > 40 caracteres, duplicado sem distinção de maiúsculas, acentos) e apagar (ativo e último são recusados pelo daemon; a GUI nem oferece) (T2).
6. (Extra) Segunda execução da GUI traz a janela existente e sai com 0; falha de `systemd-run`/GUI ausente vira notificação legível, não silêncio (T5, T8).

use ghub_ipc::DeviceState;

pub const MAX_LEVELS: usize = 5;

#[derive(Debug, Clone, PartialEq, Eq, Default)]
pub struct DpiRange { pub min: u32, pub max: u32, pub step: u32, pub list: Vec<u32> }

#[derive(Debug, Clone, PartialEq, Eq, Default)]
pub struct Levels { pub levels: Vec<u32>, pub active: u32 }

impl DpiRange {
    pub fn from_state(s: &DeviceState) -> Self {
        DpiRange { min: s.dpi_min, max: s.dpi_max, step: s.dpi_step, list: s.dpi_list.clone() }
    }

    pub fn validate(&self, dpi: i64) -> Result<u32, String> {
        if self.max == 0 && self.list.is_empty() {
            return Err("Faixa de DPI desconhecida (mouse desconectado).".into());
        }
        if dpi <= 0 {
            return Err("Informe um DPI maior que zero.".into());
        }
        let v = u32::try_from(dpi).map_err(|_| format!("O DPI máximo é {}.", self.max))?;
        if !self.list.is_empty() {
            return if self.list.contains(&v) { Ok(v) } else { Err("Este DPI não é suportado pelo mouse.".into()) };
        }
        if v < self.min { return Err(format!("O DPI mínimo é {}.", self.min)); }
        if v > self.max { return Err(format!("O DPI máximo é {}.", self.max)); }
        if self.step > 0 && (v - self.min) % self.step != 0 {
            return Err(format!("Use múltiplos de {} (a partir de {}).", self.step, self.min));
        }
        Ok(v)
    }

    pub fn snap(&self, dpi: u32) -> u32 {
        if let Some(c) = self.list.iter().min_by_key(|c| c.abs_diff(dpi)) { return *c; }
        let v = dpi.clamp(self.min, self.max.max(self.min));
        if self.step == 0 { return v; }
        let r = (v - self.min) % self.step;
        let down = v - r;
        if r * 2 >= self.step && down + self.step <= self.max { down + self.step } else { down }
    }
}

pub fn set_level(l: &Levels, r: &DpiRange, index: usize, dpi: i64) -> Result<Levels, String> {
    if index >= l.levels.len() { return Err("Nível inexistente.".into()); }
    let v = r.validate(dpi)?;
    let mut out = l.clone();
    out.levels[index] = v;
    Ok(out)
}

pub fn add_level(l: &Levels, r: &DpiRange) -> Result<Levels, String> {
    if l.levels.len() >= MAX_LEVELS {
        return Err(format!("O máximo é {MAX_LEVELS} níveis."));
    }
    let last = l.levels.last().copied().unwrap_or(r.min);
    let mut out = l.clone();
    out.levels.push(r.snap(last.saturating_mul(2)));
    Ok(out)
}

pub fn remove_level(l: &Levels, index: usize) -> Result<Levels, String> {
    if l.levels.len() <= 1 { return Err("É preciso manter ao menos um nível.".into()); }
    if index >= l.levels.len() { return Err("Nível inexistente.".into()); }
    let mut out = l.clone();
    out.levels.remove(index);
    let a = l.active as usize;
    let new_active = if index < a { a - 1 } else { a };
    out.active = new_active.min(out.levels.len() - 1) as u32;
    Ok(out)
}

pub fn select_level(l: &Levels, index: usize) -> Result<Levels, String> {
    if index >= l.levels.len() { return Err("Nível inexistente.".into()); }
    let mut out = l.clone();
    out.active = index as u32;
    Ok(out)
}

pub const MAX_NAME_CHARS: usize = 40;

pub fn validate_profile_name(raw: &str, existing: &[String]) -> Result<String, String> {
    let name = raw.trim();
    if name.is_empty() { return Err("Digite um nome para o perfil.".into()); }
    if name.chars().count() > MAX_NAME_CHARS {
        return Err(format!("O nome pode ter no máximo {MAX_NAME_CHARS} caracteres."));
    }
    if existing.iter().any(|e| e.trim().to_lowercase() == name.to_lowercase()) {
        return Err("Já existe um perfil com esse nome.".into());
    }
    Ok(name.to_string())
}

/// O daemon recusa apagar o perfil ativo e o último; a GUI nem oferece.
pub fn can_delete(profiles: &[String], active: &str, name: &str) -> bool {
    profiles.len() > 1 && name != active && profiles.iter().any(|p| p == name)
}

use std::time::{Duration, Instant};

#[derive(Debug)]
pub struct Debouncer<T> { delay: Duration, pending: Option<(T, Instant)> }

impl<T> Debouncer<T> {
    pub fn new(delay: Duration) -> Self { Debouncer { delay, pending: None } }
    /// Substitui o valor pendente e reinicia o prazo.
    pub fn push(&mut self, value: T, now: Instant) { self.pending = Some((value, now + self.delay)); }
    pub fn take_due(&mut self, now: Instant) -> Option<T> {
        match &self.pending {
            Some((_, due)) if *due <= now => self.pending.take().map(|(v, _)| v),
            _ => None,
        }
    }
    pub fn flush(&mut self) -> Option<T> { self.pending.take().map(|(v, _)| v) }
    pub fn peek(&self) -> Option<&T> { self.pending.as_ref().map(|(v, _)| v) }
    pub fn next_deadline(&self) -> Option<Instant> { self.pending.as_ref().map(|(_, d)| *d) }
}

struct Controller {
    api: Arc<dyn DaemonApi>,
    cfg: Config,
    sink: Box<dyn Fn(Update) + Send>,
    selected: Option<String>,
    autostart: Option<bool>,
    last: ViewState,
    pending: Debouncer<(Vec<u32>, u32)>,
    refresh_at: Option<Instant>,
}

pub fn spawn(api: Arc<dyn DaemonApi>, cfg: Config, rx: Receiver<Msg>, sink: Box<dyn Fn(Update) + Send>) -> JoinHandle<()> {
    std::thread::spawn(move || {
        let mut c = Controller {
            autostart: api.autostart(), api, cfg, sink, selected: None,
            last: ViewState::default(), pending: Debouncer::new(cfg.debounce), refresh_at: None,
        };
        c.refresh();
        loop {
            let deadline = [c.pending.next_deadline(), c.refresh_at].into_iter().flatten().min();
            let msg = match deadline {
                Some(d) => match rx.recv_timeout(d.saturating_duration_since(Instant::now())) {
                    Ok(m) => Some(m),
                    Err(RecvTimeoutError::Timeout) => None,
                    Err(RecvTimeoutError::Disconnected) => break,
                },
                None => match rx.recv() { Ok(m) => Some(m), Err(_) => break },
            };
            match msg {
                Some(Msg::Quit) => break,
                Some(Msg::Command(cmd)) => c.command(cmd),
                Some(Msg::Event(_)) => { c.refresh_at.get_or_insert(Instant::now() + c.cfg.coalesce); }
                None => {}
            }
            let now = Instant::now();
            if let Some(p) = c.pending.take_due(now) { c.write_levels(p); c.refresh(); }
            if c.refresh_at.is_some_and(|t| t <= now) { c.refresh_at = None; c.refresh(); }
        }
        if let Some(p) = c.pending.flush() { c.write_levels(p); }
    })
}

        }
        // Mantém a ordem: a edição pendente do slider vai antes de qualquer outro comando.
        if let Some(p) = self.pending.flush() { self.write_levels(p); }
        match cmd {
            Command::SetDpiLevels { .. } => unreachable!(),
            Command::SetActiveLevel(i) => self.with_device(|c, id| c.api.set_active_dpi_level(&id, i)),
            Command::SetPolling(hz) => self.with_device(|c, id| c.api.set_polling_rate(&id, hz)),
            Command::ApplyProfile => {
                let level = self.last.device.as_ref().map(|d| d.active_level);
                match level { Some(l) => self.with_device(|c, id| c.api.set_active_dpi_level(&id, l)),
                              None => self.fail("Nenhum dispositivo selecionado.") }
            }
            Command::ActivateProfile(n) => { let r = self.api.activate_profile(&n); self.report(r); }
            Command::CreateProfile(n) => { let r = self.api.create_profile(&n); self.report(r); }
            Command::DeleteProfile(n) => { let r = self.api.delete_profile(&n); self.report(r); }
            Command::SelectDevice(id) => self.selected = Some(id),
            Command::SetAutostart(on) => {
                if let Err(e) = self.api.set_autostart(on) { self.fail(e); }
                self.autostart = self.api.autostart();
            }
            Command::StartDaemon => { if let Err(e) = self.api.start_daemon() { self.fail(e); } }
            Command::Rescan => { let r = self.api.rescan(); self.report(r); }
            Command::Refresh => {}
        }
        self.refresh();
    }

    fn with_device(&self, f: impl FnOnce(&Self, String) -> Result<(), ApiError>) {
        match self.device_id() {
            Some(id) => { let r = f(self, id); self.report(r); }
            None => self.fail("Nenhum dispositivo selecionado."),
        }
    }
}
